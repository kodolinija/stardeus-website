<p>Each <span class="accent"><b>friendly being</b></span> has one of the following <span class="accent"><b>Combat Reactions</b></span>:<br> - <span class="accent"><b>Free Will</b></span>: The being will <span class="accent"><b>fight</b></span> while it holds a <span class="accent"><b>weapon</b></span> it can use and is not badly hurt, and <span class="accent"><b>flee</b></span> otherwise.<br> - <span class="accent"><b>Fight</b></span>: The being will <span class="accent"><b>shoot</b></span> enemies it can hit from where it stands, or go at enemies <span class="accent"><b>close by</b></span> with a melee weapon, then go back to work. <span class="accent"><b>Draft</b></span> it to send it into the fight.<br> - <span class="accent"><b>Flee</b></span>: The being will <span class="accent"><b>run away</b></span> from enemies close by, and work otherwise.<br> - <span class="accent"><b>Ignore</b></span>: The being will focus on <span class="accent"><b>colony tasks</b></span> and personal <span class="accent"><b>needs</b></span>, ignoring enemies unless <span class="accent"><b>provoked</b></span> or given a <span class="accent"><b>Direct Order</b></span>.</p>
