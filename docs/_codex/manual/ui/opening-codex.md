<p>The <span class="accent"><span class="accent"><b>Operations Manual</b></span></span> explains how your ship works, one short topic at a time. Topics like this one will pop up as you play.</p>

<p>You can open the full manual at any time from the <span class="accent"><b>Codex</b></span> app in the <span class="nobr"><kbd title="Keyboard: K">K</kbd></span> <span class="accent"><span class="accent"><b>Apps</b></span></span> tab of the <span class="nobr"><a href="/codex/database/objects/devices/ship-computer/">Ship Computer</a></span>, or by searching for <span class="accent"><b>Codex</b></span> in <span class="nobr"><kbd title="Keyboard: Tab">Tab</kbd></span> <span class="accent"><span class="accent"><b>Quick Search</b></span></span>.</p>

<figure class="codex-image"><img src="/img/codex/UI/CodexSequence.png" alt="Operations Manual - CodexSequence" loading="lazy"></figure>
<p>Once you have read a topic, mark it as learned to track your progress.</p>
